# Правила проекта Rust AutoConnect

Эти правила действуют только в этом проекте, поверх глобальных правил.

## Anti-cheat безопасность (КРИТИЧНО)

- **Никогда не читай и не пиши память процесса Rust**, не делай code injection, DLL injection, memory hacking — это гарантированный VAC-бан.
- **Никогда не используй RCON** для управления игрой напрямую.
- Единственные разрешённые способы взаимодействия с игрой:
  - запуск через `steam://connect/...` (Steam сам запускает игру)
  - **чтение** (только чтение, не запись) собственного лог-файла Rust, чтобы подтвердить подключение
  - определение запущен ли процесс Rust через `psutil` (просто проверка списка процессов, не вмешательство)
- Если в будущей задаче потребуется "заглянуть внутрь" игры глубже, чем чтение лога — останавливайся и спрашивай пользователя, а не ищи обходной путь.

## Структура интерфейсов

- `src/web/` — текущий основной интерфейс (веб, запускается по умолчанию). Именно сюда идут новые фичи.
- `src/gui/` (CustomTkinter) — старый интерфейс, запускается только через `--tk`/`--legacy`. Не вкладывай туда много усилий, если явно не попросили.

## Вайпы и время

- Логика расписания вайпов (`steam_service.py`, `smart_monitor.py`) — чувствительная к ошибкам зона: ошибка в часовом поясе/времени может заставить пользователя зайти на старую карту или пропустить вайп. Любые правки здесь — проверяй на реальных датах, а не только юнит-тестами с моками.

## Переводы (i18n)

- `assets/i18n/en.json` и `ru.json` — поддерживаются в актуальном состоянии. Остальные языки (DE, ES, FR, CN, UK) могут отставать.
- Если добавляешь новый пользовательский текст — обнови как минимум EN и RU. Не обязательно переводить на все 7 языков сразу, но скажи пользователю какие языки отстали.

## Веб-сервер (src/web)

- Все `/api/*` эндпоинты защищены токеном сессии (`X-AutoConnect-Token`) — см. `session_token_middleware` в `server.py`. Любой новый эндпоинт автоматически попадает под защиту, если начинается с `/api/`. Не отключай эту проверку.
- Данные, приходящие от пользователя (имя сервера, IP, текст лога), рендерятся в `innerHTML` в некоторых местах фронтенда — экранируй через `escapeHtml()` (см. `api.js`), не выводи напрямую.
